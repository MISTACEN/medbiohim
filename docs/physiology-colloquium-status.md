## 🔍 Особенности реализации:

- Данные разделены на 4 логических модуля в JSON файле
- Каждый вопрос имеет структуру: question/options/correct/why/answer/simple
- Для тестов с несколькими правильными вариантами используется массив correct []
- Вопросы с неоднозначными ответами помечены в коде комментариями для сверки
