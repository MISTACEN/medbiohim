# «Пирамида знаний» и химия: план внедрения

> 2026-11-03. Первый шаг уже в проде: разбор ДЗ из Telegram раскладывает пункты
> на «База / Основной / Углубление».

## 1. Что уже есть

- **Разметка уровней в заданиях.** Бот и API помечают каждый пункт задания
  уровнем (`telegram-classify.ts` → `buildHomeworkLevels`) и печатают секции
  «🧱 База (вызубрить)», «📖 Основной блок», «🔬 Углубление» в описании задания,
  которое видно на `/homework`.
- **Маркеры-триггеры.** «Вызубрить», «наизусть», «нормы», «термины», «цифры»,
  «латынь», «формулы» → база; «клиническая задача», «патофизиология»,
  «углубление», «на 5», «разбор» → углубление; остальное → основной блок.
- **Карточки SRS** (`/cards`, бот `/drill`) — готовая механика интервального
  повторения, на которую можно посадить «Базу».
- **Химия**: движок формул (`src/lib/chemistry/formula.ts`), калькуляторы
  (`/calculators`), бот `/challenge` и `/formula`.

## 2. Этапы

### Этап 1 — разметка и отображение (сделано)
- Уровни в заданиях из Telegram, секции в описании, счётчики в ответе бота.
- Критерий: задание «1. Вызубрить нормы 2. Прочитать лекцию 3. Клиническая
  задача» показывает три секции.

### Этап 2 — «Лестница» в личном плане
- В карточке темы — шаги 1–4 с чекбоксами и индикатором «Готовность к занятию»
  (красный, пока не закрыт Блок 1).
- Данные: уровни пунктов уже есть; нужен план-агрегат (`planner`/`plans`) и
  хранение прогресса по шагам.
- Критерий: студент видит «Сначала база», отмечает шаг 1 и получает зелёный
  индикатор.

### Этап 3 — Workshop: разметка материалов по блокам
- При загрузке конспекта/фотолекции — выбор блока (база / основной / углубление).
- «Умный импорт» (`smart-paste.ts`) распознаёт маркеры («вызубрить», «выучить
  наизусть», «прочитать») и раскладывает пункты автоматически — та же эвристика,
  что в боте.
- Критерий: материал помечен блоком и фильтруется по нему в Workshop.

### Этап 4 — флеш-карты из «Базы»
- Из пунктов базы генерируются карточки SRS с вопросом/ответом (норма, термин,
  цифра, формула).
- Утро в боте: «Норма палочкоядерных нейтрофилов?» → «Показать ответ» (уже есть
  `/drill` и `/daily`).
- Критерий: 10 карточек из базы темы приходят в чат и учитываются в SRS.

### Этап 5 — тесты по уровням
- Вопросы маркируются: «на 3» — только база, «на 4» — понимание, «на 5» —
  углубление (сейчас так устроен режим экзамена в гистологии).
- Критерий: тест темы собирается из вопросов выбранного уровня.

## 3. Химия и точные дисциплины

Отличия от гистологии: важны формулы, алгоритмы и расчёты, а не только
запоминание.

1. **Банк формул.** LaTeX/Unicode-рендер в редакторе и материалах (уже есть
   `src/lib/chemistry/formula.ts` и `latex-unicode.ts` в API). Формула хранится
   как отдельная сущность с расшифровкой и примером.
2. **Алгоритмы решения.** Блок «Основной» для химии — пошаговый чек-лист
   (найти степени окисления → определить окислитель → уравнять), а не текст.
3. **Задачи с автопроверкой.** Числовой ответ + допуск, разбор ошибки; для
   уравнений — проверка баланса атомов.
4. **Уровни в химии.** База: валентности, атомные массы, номенклатура, константы.
   Основной: механизмы и алгоритмы. Углубление: клинические задачи, многостадийный
   синтез, биохимические пути.
5. **Бот для химии.** `/challenge` уже даёт реакцию; следующий шаг — проверка
   ответа (баланс/продукт) и формула дня с интервальным повторением.

## 4. Порядок работ

1. Экран «Лестницы» в плане (этап 2) — даёт главный эффект «сначала база».
2. Автогенерация карточек из базы (этап 4) — использует готовый SRS.
3. Разметка Workshop (этап 3) — контент от старшекурсников.
4. Химия: банк формул и автопроверка задач — после стабилизации уровней.
