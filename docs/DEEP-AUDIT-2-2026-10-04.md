## 4. Остались backend traces без полноценного текущего UI

### learning_sessions
Есть реальные DB rows и /sessions API, но current preparation/training UI используют dedicated session endpoints. Generic sessions API не является текущей пользовательской dependency.

Статус: DEFERRED. Не удалять до проверки legacy consumers.

### material source metadata page
`/materials/source` — реальная страница метаданных content source, но сейчас не является основной точкой навигации. Generic materials UI открывает converted content или external source.

Статус: P2. Следующий шаг — либо дать пользователю явную кнопку «Метаданные источника», либо оставить как internal/debug route.

### duplicate backend routes
Реальные handlers остаются в legacy/dedicated route files одновременно:
- domain + domain_rest;
- admin + admin_rest;
- platform + progress_rest;
- platform + community_rest;
- другие dedicated REST + legacy aggregate routes.

Это не mock. Это архитектурный долг, который лучше закрывать отдельным route-contract audit, чтобы не сломать порядок регистрации handlers.

## 7. Final audit rule

Новый критерий MEDBIOHIM:

Функция считается сделанной только если одновременно:
1. есть backend implementation;
2. есть DB/storage contract;
3. есть пользовательский путь из UI;
4. он не зависит от fake/mock source;
5. CI/build проходят;
6. target environment отвечает корректно.
