## Инфраструктура (справка)

- Фронт: Next.js → `/api/v1` → Cloudflare Workers (`medbiohim-api.ryazansevegor.workers.dev`)
  → Supabase (Postgres + auth) + Upstash (Redis/Blob).
- Локальное окружение: `.env.local` (не коммитится) с реальными ключами Supabase;
  прямой доступ к Postgres — через `DB_URL` (session pooler, `pg` ставится
  `npm i --no-save pg`).
- Миграции: `database/migrations/` применяются в Supabase (SQL Editor или через
  `DB_URL`).
