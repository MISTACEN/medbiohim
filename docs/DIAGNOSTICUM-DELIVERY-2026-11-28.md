## Осталось

1. `supabase migration repair --status applied <58 версий>` — запись в ledger
   прод-базы. 58 локальных файлов применялись вручную и не отмечены; на работу
   сайта не влияет, влияет на строгость сверки. Нужно отдельное «да».
2. Чужие незакоммиченные правки физиологии (`Colloquium.tsx`, `TestRunner.tsx`,
   контент) — из-за них локально красные два чужих теста и не переключается
   ветка. Зона параллельного агента.
3. Косметика: в `EM-CAPTIONS-MATCHING-2026-11-28.md` фразу «2 пропущены» стоит
   читать как «2 сохранили свои подписи» (архивный заголовок их бы обеднил).

```bash
npm run typecheck && npm run lint && npm run test:unit   # фронтенд
cd workers/api && npm run check                          # воркер
npm test                                                 # архитектура и токены
node scripts/check-migration-ledger.mjs                   # ledger (нужен pg + DB_URL)
```
