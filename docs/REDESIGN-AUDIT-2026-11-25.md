## 6. Целевая структура (карта будущего)

**Тестирование — одно рабочее пространство `/tests` с вкладками:**

1. `Назначенные` — блок сверху всегда виден, обязательные, со статусом и сроком.
2. `Каталог` — предмет → раздел → тема → банк; строка темы показывает неделю,
   тип занятия, число банков/вопросов, прогресс, кнопки «Открыть банк»,
   «Выбрать режим», «Начать».
3. `Подготовка` — количество (10 из 200 = 10), режимы: проверка сразу,
   проверка в конце, экзамен без эталонов, весь банк по порядку; пирамида
   (все/база/понимание/применение).
4. `Прохождение` — один экран, интерфейс меняется по режиму и типу задания
   (один/несколько ответов, свободный, число, соответствие, нумерация,
   изображения и формулы).
5. `Результаты` — проценты, время, по темам, вопросы на повтор.
6. `Разбор` и `Все вопросы и ответы` — эталоны, скрытие ответов, фильтр по теме.
7. `История` — попытки и продолжение.

**Редактор** `/admin/content` (или `/teacher/content`): банки, вопросы, типы,
привязки к темам/лекциям, уровни пирамиды, перенос между банками, импорт и
экспорт, предпросмотр, проверка целостности, история изменений.

**Химия** — один вход: теория → тесты → формулы и справочник → задачи, с
рендером формул (Chemfig/изображения) и доступом к справочным данным в режимах,
где это разрешено.

**Гистология** — единое пространство с навигацией по направлениям и общей
контекстной панелью препарата: атлас → карточки → диагностикум → возврат к тому
же препарату. Отдельные банки: микропрепараты и электронограммы. Диагностики —
наборы (первая 18 позиций, вторая проектируется).

**Остальные разделы** — материалы + библиотека + лекции в один раздел с
вкладками; прогресс/журнал/закладки в «Прогресс»; сообщество и мастерская
остаются самостоятельными.
