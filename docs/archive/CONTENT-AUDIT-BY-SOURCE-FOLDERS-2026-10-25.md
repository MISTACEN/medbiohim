## Химия — 10 файлов, из них 7 уникальных, на сайт не привязаны

Дубли по md5:

- `chem1.pdf` = `Отсканированный документ 2.pdf`
- `chem2.pdf` = `Отсканированный документ 3.pdf`
- `chem3.pdf` = `Отсканированный документ.pdf`

Уникальные: `166_…ацетоуксусного эфира…`, `Д) прегнан…`, `МИНИСТЕРСТВО_ОБРАЗОВАНИЯ…`,
`очной_кислоты_С_НАД…`, `chem1/2/3` (7 без дублей).

Вопросы в базе: 181 у `chemistry_organic_physical` и 161 у «Неорганической химии»;
ни один из PDF не привязан как материал предмета (`subject_materials` пуст).
Размеры 15–100 МБ — это сканы, их надо загружать в B2, а не в `public/`.

## Что осталось загрузить (нужны доступы)

1. Два видео по гистологии (~1 ГБ) → Backblaze B2, затем записи в `materials`.
2. 213 файлов «Учебники+атласы» → B2 (или отбор: 10–15 ключевых атласов).
3. 7 сканов химии → B2 + привязка к предмету химии.

В API уже есть подпись ссылок B2 (`B2_KEY_ID`, `B2_APPLICATION_KEY`, `B2_BUCKET`),
поэтому после загрузки файлы откроются без изменений кода.
