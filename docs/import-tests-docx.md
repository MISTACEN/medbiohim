# Импорт теста из DOCX файла

## Обзор

Система позволяет преподавателям быстро загружать тесты из Microsoft Word (.docx) файлов, автоматически распознавать вопросы и варианты ответов, проверять корректность данных и сохранять в систему.

## Где найти

- **URL**: `/admin/test-import`
- **Доступ**: Только администраторы (role: admin)
- **Навигация**: Админ → Импорт → DOCX → Тест

## Поддерживаемый формат файла

### Структура документа

```
[Заголовок] Название теста или предмета

1. Текст первого вопроса
@1. Правильный вариант
#2. Неправильный вариант
#3. Другой неправильный вариант

2. Текст второго вопроса
@1. Единственный правильный ответ
#2. Неправильный
```

### Маркировка вариантов ответов

| Маркер | Значение | Пример |
|--------|----------|--------|
| `@1.` | **Правильный** вариант ответа | `@1. Верный ответ` |
| `#1.` | Неправильный вариант | `#1. Неверно` |

**Важно:** 
- Строка `1. Текст` всегда считается новым вопросом, а не вариантом ответа
- Для каждого вопроса должен быть хотя бы один вариант с `@`
- Префикс `@` означает "правильный", `#` - "неправильный"

### Пример файла

```
Элементы теории вероятностей

1. Любой факт, который может произойти или не произойти в результате опыта со случайным исходом в теории вероятностей называют:
@1. элементарным событием
#2. общим решением
#3. частным решением
#4. частотой
#5. вероятностью

2. Случайное выпадение числа при бросании игральной кости в теории вероятностей называют:
@1. случаем
#2. событием
#3. исходом
#4. результатом
```

## Процесс загрузки

### Шаг 1: Загрузка файла

1. Перейдите на страницу `/admin/test-import`
2. Перетащите файл `.docx` в область загрузки или нажмите "Выбрать файл"
3. Система автоматически разберет файл

### Шаг 2: Просмотр результатов

После загрузки система покажет:

- **Название теста** (первая непустая строка документа)
- **Количество вопросов** (автоматически подсчитано)
- **Все вопросы с вариантами ответов**

Можно отредактировать:
- Название теста
- Предмет (выбор из списка)
- Slug (латиница, цифры, дефис)
- Проходной балл (по умолчанию 70%)
- Текст вопросов
- Варианты ответов

### Шаг 3: Проверка

Перед сохранением:
- Внимательно просмотрите все вопросы
- Убедитесь, что правильные ответы помечены правильно
- Отредактируйте текст при необходимости

### Шаг 4: Сохранение

Нажмите "Сохранить тест":
- Данные сохраняются в базу Supabase
- Можно опубликовать сразу или сохранить как черновик
- Студенты увидят тест только после публикации

## Технические детали

### Парсинг документа

Используется библиотека JSZip для чтения внутреннего XML структуры .docx:
- Извлекается `word/document.xml`
- Разбирается структура параграфов (`w:p`)
- Распознаются номера вопросов и вариантов
- Обрабатываются переносы текста между строками

### Выбор предмета

Предмет не угадывается: администратор выбирает его из списка предметных адаптеров (`src/lib/learning/subjects.ts`). Slug теста генерируется из названия и правится вручную — API принимает только латиницу, цифры и дефис.

## Ограничения

- Только формат `.docx` (старый `.doc` не поддерживается)
- Минимум 1 вопрос с правильным ответом
- Вопрос должен начинаться с цифры и точки (например, `1. `)

## Решение проблем

### "В файле не найдено вопросов"

Проверьте формат:
- Вопросы должны начинаться с `1. `, `2. `, и т.д.
- Должен быть хотя бы один вариант с `@N.`

### "Не найден word/document.xml"

Пересохраните файл в формате `.docx`:
- В Microsoft Word: Файл → Сохранить как → Word Document (.docx)
- Или используйте онлайн конвертер

### Некоторые вопросы пропущены

- Проверьте нумерацию вопросов (должна быть последовательная)
- Убедитесь, что между вариантами нет пустых строк с текстом

## Сравнение с Excel-импортом

| Характеристика | DOCX импорт | Excel импорт |
|----------------|-------------|--------------|
| Быстрота загрузки | ⚡ Очень быстро (1 клик) | 🐢 Требует подготовки файла |
| Автоопределение | ❌ Предмет выбирается из списка | ❌ Нужно заполнять вручную |
| Редактирование | ✅ На лету | ❌ Требует редактирования Excel |
| Подходит для | 📝 Готовых тестов | 🗂️ Пакетной загрузки |
| Предпросмотр | ✅ Полная проверка | ⚠️ После загрузки |

## API

### `importTestFromDocx(file: File)`

Асинхронная функция для парсинга DOCX файла.

**Возвращает:**
```typescript
{
  title: string;           // Название теста
  sourceName: string;      // Имя исходного файла
  questions: ParsedTestQuestion[];
  rawMarkdown: string;     // Markdown представление
  parsedAt: string;        // Время парсинга
}
```

## Примеры использования

### Преподаватель хочет загрузить готовый тест

1. Открыл `.docx` файл с тестом
2. Перешел на `/admin/test-import`
3. Перетащил файл в окно браузера
4. Проверил вопросы (исправил 1 опечатку)
5. Сохранил - готово! (~30 секунд вместо ~15 минут в Excel)

### Импорт серии тестов

Для массовой загрузки:
1. Создать шаблон в Word
2. Использовать стандартную нумерацию
3. Загружать по одному файлу
