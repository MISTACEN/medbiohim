# Концепция платформы Медбиохим

## Единица работы

**Предмет + Курс + Семестр** — главный контекст обучения.

Пользователь выбирает предмет один раз. Все связанные разделы открываются внутри него и не требуют повторного выбора предмета.

## Общая оболочка

Главное меню:
- Главная
- Поиск
- Расписание
- Предметы
- Задания
- Прогресс
- Сообщество
- Калькуляторы
- AI-тьютор
- Настройки
- Помощь
- Админ

## Страница предмета

Каноническая структура:

**Учебный план · Билеты · Тесты · Практика · Лекции · Материалы · Микропрепараты · SRS · Прогресс**

Внутри предмета:
- учебный план связывает темы и занятия;
- материалы открываются без повторного выбора предмета;
- тренажёр использует только контент своего предмета;
- атлас является полноценным разделом контента тренажёра;
- подробные документы и исходные файлы находятся в «Материалах».

## Важные правила

- Билеты ≠ SRS.
- Банк вопросов ≠ тест.
- Контент строго привязан к `subject_id/slug`.
- Гистология не должна подставлять материалы другого предмета.
- Экспериментальные UI-темы не считаются production design без отдельного продвижения.
