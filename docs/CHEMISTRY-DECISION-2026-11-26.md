# Химия: решение по черновику «Химия · часть 1»

Дата решения: 2026-11-26. База: `main` @ `7bac3d35`.
Основание: [CHEMISTRY-RECONCILIATION-2026-11-25.md](CHEMISTRY-RECONCILIATION-2026-11-25.md)
(сверка двух наборов) и [02-Химия-и-единая-система-тестирования.md](concept/02-Химия-и-единая-система-тестирования.md)
(приоритет 2).

## Решение

1. **Канон — опубликованный набор «Оргхимия»** (18 тем, 997 вопросов, 20
   опубликованных тестов). Он не менялся.
2. **Черновик «Химия · часть 1» не публикуется.** 18 черновых тестов помечены
   архивом (`tests.archived_at`), чтобы их нельзя было опубликовать случайно.
   Вопросы и связи **не удалены** — 577 связей на месте.
3. **Автоматический перенос вопросов из черновика в канон не делается.**
   Текстовое совпадение не равно совпадению задания: формулировки в черновике
   другие («Название продукта димеризации ацетилена» против «Названия
   соединений, синтезируемых в условиях реакции Лебедева»), это требует ручной
   семантической сверки, а не `md5`.
4. **22 задания без пары в каноне — очередь ручной проверки**, а не импорт.
   У всех 577 строк черновика `media = []`: рисунки, проекции Фишера и сканы к
   заданиям не приложены, часть заданий без них нерешаема (см. приложение).
5. **Задания на соответствие не импортируются**, пока парсер не вытащит левую
   колонку, правую колонку и ключ пар, и в enum `question_type` не появится
   `match` (сейчас в enum: `mcq`, `open`, `problem`, `theory`, `practical`).
6. **29 mcq без ключа** (из сверки 2026-11-25) не импортируются: без эталона
   вопрос нельзя проверить, он будет портить статистику.

Два ранних черновика `dvgmu-orgchem-2016:theme-1..3` (98 вопросов) этим
решением **не затрагиваются** — это отдельный импорт со своим источником; их
судьба решается вместе с разбором парсера.

## Код-часть: три красных теста химии закрыты (2026-11-26)

После решения по черновику `npm test` оставался красным на трёх тестах химии.
Все три падали независимо от решения, но относились к тому же направлению:

1. **`status-tokens`** — [`EffectsReference.tsx`](../src/modules/subjects/submodules/chemistry/EffectsReference.tsx)
   задавал знак эффекта сырыми `emerald/rose/amber`. Теперь `+I` — токены
   `--status-ok-*`, `-M` — `--status-critical-*`, `+M` — `--status-warn-*`,
   `-I` остался декоративным `sky`. Смысл знака сохранился, тёмная тема и
   контраст работают через тему.
2. **`subject-submodules`** — в реестре `src/modules/subjects/registry.json`
   не было вкладки `effects`, хотя раздел есть в `ChemistryModule`. Вкладка
   добавлена на своё место (после «Структуры») с тем же текстом-подсказкой;
   отдельной страницы у раздела нет, поэтому `href` не задаётся — тест
   «ссылки ведут на существующие страницы» такие вкладки пропускает.
3. **`portal-content` (`mc-index`)** — проверка требовала ≥ 20 банков, но 17
   банков химии из сборника ДВГМУ 2016 ещё 2026-11-24 осознанно выведены в
   `archivedTests` (коммит `bd16c89d`, «заменено тематическими тестами
   chemistry_master_documents v3»). Порог приведён к фактическим 16 живым
   банкам, а вместо ослабления добавлен новый тест-страж: архивные банки должны
   иметь дату, причину, файл для отката и не появляться в выдаче.

Проверки: `npm test` — **394/394**, `npx tsc --noEmit` — 0, `eslint` по
изменённым файлам — 0, `npm run build` — exit 0.
