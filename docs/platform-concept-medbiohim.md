# Концепция платформы Медбиохим

Единица работы: **Предмет + Курс + Семестр**.

Короткое меню: Главная, Поиск, Расписание, Предметы, Задания, Прогресс, Сообщество, Калькуляторы, AI-тьютор, Настройки, Помощь, Админ.

На странице предмета: план, билеты, практика, лекции, материалы, SRS (общие/личные), прогресс.

Билеты ≠ SRS. Строгий match банка по slug (гистология не подставляет неорганику).

См. также `docs/subject-content-matrix.md`.
