# Практика — детальный разбор (`#/practice`)

> Дополнение к [README.md](README.md). Проверено вживую 16.11.2026: карточка дня, все фильтры, страница «Тренажёр по разделам», демо-диагностика. Скриншоты: `screens/03-practice.png`, `34-practice-card.png`, `35-practice-trainer.png`, `36-practice-demo.png`.

## 1. Структура экрана (сверху вниз)

1. **Заголовок:** «Практика» + подпись «Сначала — что нужно именно вам, ниже — все тренажёры».
2. **Блок «Для вас»** — «по тому, что вы открывали и где ошибались». Персонализация по истории просмотров и ошибок. В пустом аккаунте: «Подборка появится, когда вы откроете первые материалы и тесты».
3. **Блок «Повторение»** — «На сегодня всё повторено» + кнопка «Повторить». Это вход в SRS-очередь (интервальное повторение).
4. **Карточка дня · 1 из 5** — ежедневная карточка: предмет, вопрос, кнопка «Показать ответ», после раскрытия — правильный ответ, короткое пояснение «Базовый факт по предмету» и две кнопки самооценки: **«Помню» / «Не помню»**. Рядом всегда есть «Дальше» (пролистать пятёрку).
5. **«Все тренажёры»** — фильтры-чипы и сетка карточек.

## 2. Карточка дня: механика

Проверено на карточке:
- Предмет: Анатомия.
- Вопрос: «Какие мышцы образуют вращательную манжету плеча?».
- После «Показать ответ»: «Надостная, подостная, малая круглая, подлопаточная (SITS)» + подпись «Базовый факт по предмету».
- Кнопки «Помню» / «Не помню» — это не проверка знаний, а **самооценка для планировщика повторений**: ответ уходит в SRS и влияет на дату следующего показа.

**Что здесь важно для «Изучай»:** карточка дня — не тест, а ежедневная привычка на 30–60 секунд. Одна карточка, один факт, один ответ, две кнопки. Никаких штрафов и таймеров.

## 3. Фильтры: что реально показывают

Фильтры работают как категории, а не как поиск. Состав на дату аудита:

| Фильтр | Что показывает |
|---|---|
| **Все** | 30+ карточек: тренажёры, ИИ-агент, КР, шкалы, курсы, стоматология |
| **Мои предметы** | Только общие инструменты, пока нет купленных предметов: «Тренажёр по разделам», «Пробелы в знаниях», «Дерево навыков», «ИИ-агент к экзамену», «Шкалы и калькуляторы». То есть фильтр = «доступное мне», а не «все предметы» |
| **Экзамены** | Аккредитация, ГИА, Клинические рекомендации |
| **Клиника** | Симулятор терапевта, Тренажёр ЭКГ, Курс ЭКГ, Задачи по хирургии, Неврология, Лабораторные заключения, Навык за вечер, Микронавыки, Рацион ребёнка, Рентген, УЗИ сердца, Патанатомия, Гистология |
| **База** | Латынь, Рецепты, Возбудители, Паразитология, Проводящие пути, Метаболические пути, Лаборатория молекул, Формулы, Химия: задачи |
| **Стоматология** | Пропедевтика, Хирургия |

**Наблюдение:** категории не пересекаются с «предметами» — это именно типы практики. Один и тот же предмет может быть в разных категориях. Для своей реализации лучше хранить у тренажёра набор тегов (`exam`, `clinical`, `basic`, `dental`), а не одну категорию.

## 4. «Тренажёр по разделам» — самый показательный экран

Открывается из карточки «Тренажёр по разделам». Что внутри:

- Заголовок: «Тренажёр по разделам», подпись «Практика и клинические задачи по каждому разделу».
- **Предмет:** «Нормальная анатомия — 6979 вопросов».
- Подпись: «Практика и клинические задачи по каждому разделу: ответ, разбор, ошибки уходят в повторение. Открывается вместе с доступом к предмету».
- Две кнопки: **«Попробовать 3 вопроса»** (демо) и **«Открыть доступ»** (пейвол).
- Ссылка «Другой предмет».
- **Разделы** — карточки с количеством страниц методички и статусом:
  - Остеология — 102 страницы · «практика и клиника» · **демо**;
  - Череп — 67 · с доступом;
  - Артрология — 47;
  - Миология — 342;
  - Спланхнология / Пищеварительная — 100;
  - Дыхательная — 29;
  - Мочеполовая — 55;
  - ПНС — 147;
  - Эндокринная — 10;
  - Органы чувств — 50;
  - Клиническая анатомия.
- **«Другие тренажёры»:** Аккредитация, ГИА, КР, Симулятор терапевта, ЭКГ, Курс ЭКГ, Задачи по хирургии, Неврология.

**Что это говорит о продукте:**
- Контентная единица — не «тест», а **раздел методички** (десятки–сотни страниц), к которому привязаны вопросы, клинические задачи и разбор.
- Вопросы не отдельно от контента: «ответ, разбор, ошибки → повторение».
- Демо — ровно 3 вопроса, чтобы попробовать без оплаты. Это сильный паттерн: не «30 дней бесплатно», а «3 вопроса по реальному разделу».

## 5. Демо-диагностика («Попробовать 3 вопроса»)

Клик по «Попробовать 3 вопроса» уводит на отдельную воронку (демо-доступ), а не в обычный тренажёр:

- «Шаг 1 из 4 — Диагностика»; шаги: **Диагностика → Демо-урок → Доступ**.
- «ПРОГРЕСС ДЕМО-ДОСТУПА 0 из 3».
- «ВАША СКИДКА 0% — Пройдите демо — накопите до +30%» (геймификация скидки; для «Изучай» не переносим, но сам прогресс прохождения — да).
- «ДИАГНОСТИКА ЗНАНИЙ. Диагностика: Нормальная анатомия. Вопрос 1 из 3 · нажмите на ответ».
- Вопрос: «Axis sagittalis — это ось, направленная:»; варианты: «спереди назад», «справа налево», «сверху вниз», «снизу вверх».
- Кнопка «Сменить предмет».

**Педагогический смысл:** перед покупкой/стартом студент проходит короткую диагностику (3 вопроса), получает результат и персональный план. Это simultaneously: онбординг, прогрев и сегментация. Без скидок это можно использовать как **бесплатный вход в продукт**: «3 вопроса → узнай свой уровень → получи план на неделю».

## 6. Что ещё есть вокруг практики

- **«Пробелы в знаниях»** — темы с низкой точностью ответов за последние недели; пустое состояние: «нужно чуть больше ответов».
- **«Дерево навыков»** — отдельный экран с ветками и уровнями.
- **«ИИ-агент к экзамену»** — план и проверка до экзамена.
- **«Шкалы и калькуляторы»** — SOFA, CURB-65, Глазго, СКФ.
- **«Клинические рекомендации»** — 779 сокращённых КР.
- **Тренажёры ЭКГ/УЗИ/рентген/гистология/патанатомия** — ленты препаратов и снимков (внутри — свой плеер/карточки).

## 7. Сильные стороны практики (что копировать)

1. **Один экран = одно действие.** Карточка дня, повторение, затем каталог. Нет перегруза.
2. **Самооценка вместо жёсткого теста** в ежедневной карточке — снижает тревожность, ускоряет привычку.
3. **Ошибки уходят в повторение автоматически** — это ключевая петля: ответил → ошибся → карточка вернулась.
4. **Тренажёр привязан к разделу методички**, а не к абстрактной теме. Студент понимает, где именно дырка.
5. **Демо на 3 вопроса** по реальному разделу — честный и быстрый первый опыт.
6. **Категории практики** (экзамен/клиника/база/стоматология) помогают выбрать режим под ситуацию.
7. **Пустые состояния объясняют, что сделать**, а не просто «нет данных».

## 8. Слабые места / что не копировать

1. **Пейвол внутри практики** («Открыть доступ») — если делать «Изучай», базовые тренажёры должны быть бесплатными, иначе продукт не станет ежедневным.
2. **Скидка за прохождение демо** — манипулятивная механика; заменить на «результат диагностики + план».
3. **Категории-чипы без счётчиков** — непонятно, сколько внутри; лучше показывать количество и время.
4. **Каталог из 30+ карточек** — легко потеряться; нужна сортировка «под мой экзамен / под мой слабый раздел / новое».
5. **Нет явного «почему этот тренажёр мне»** — персонализация «Для вас» пустая, пока нет данных; нужен честный онбординг-выбор предмета и экзамена.

## 9. Мини-спека для «Изучай» (практика)

```
Экран «Практика»
├── Карточка дня (1 факт, 30–60 сек)
│   ├── вопрос
│   ├── «Показать ответ»
│   ├── ответ + 1 строка пояснения
│   └── «Помню» / «Не помню» → SRS
├── Повторение (due today)
│   ├── N карточек
│   └── «Повторить» → очередь
├── «Под мой экзамен» (3–5 тренажёров, отсортированы по слабым темам)
└── Каталог
    ├── фильтры: экзамен / клиника / база / мой предмет
    ├── карточка: название, что внутри, N вопросов, ~время, статус
    └── демо: 3 вопроса по реальному разделу
```

**Метрики практики:** доля дней с завершённой карточкой дня; медиана карточек в день; доля ошибок, вернувшихся в повторение; точность по темам; время до первого ответа после открытия экрана (< 30 сек).
