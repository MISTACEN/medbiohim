# NeoFamily Lab и Школа Сеченова — реверс функций и интеграция

Дата: 2026-10-23. Источник данных — публичная навигация и открытые страницы платформ на эту дату (HTML главных страниц и разделов). Закрытые уроки, платные материалы и API не вскрывались.

## Принципы

- Копируем **механику**, а не контент: структуру урока, типы заданий, навигацию, форматы проверки.
- Не обходим оплату, авторизацию и защиту от копирования.
- На платформы ведём **внешние ссылки** (deep links), внутри MEDBIOHIM даём свои аналоги.
- Импорт возможен только вручную: расширение читает открытую страницу по кнопке, пользователь отмечает материалы и подтверждает сохранение.

## Импорт ссылок (расширение + API)

- `POST /api/v1/integrations/imports` — `{ items: [{ title, url, kind, source, summary? }] }`, до 50 записей, дедупликация по SHA-256 от URL в рамках пользователя.
- `GET /api/v1/integrations/imports`, `DELETE /api/v1/integrations/imports/:id` — только свои записи.
- Совместимые алиасы: `POST /api/v1/integrations/fesmu/import`, `POST /api/v1/integrations/fesmu/dedup`.
- Записи лежат в `site_content` под `extimport:<user id>:<hash>`; сервисный ключ используется только на Worker, RLS-таблицы не ослаблены.
- Расширение: `browser-extension/`, сборка `npm run package`, архив `public/downloads/medbiohim-importer.zip`, инструкция `/extension`.

## Ограничения и следующий шаг

- Записи импорта пока не отображаются отдельной страницей в кабинете — доступны через API; страницу можно добавить без миграции.
- Для постоянного хранения лучше отдельная таблица `imported_sources` с RLS: текущая схема использует `site_content` как временное хранилище.
- Проверено: сборка расширения, целостность архива, ссылки манифеста; реальный импорт требует токена пользователя.
