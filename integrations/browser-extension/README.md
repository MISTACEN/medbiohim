# MEDBIOHIM Bridge — браузерное расширение

Chrome/Edge Manifest V3. Версия 0.2.0 добавляет компактную боковую панель к MVP быстрых ссылок.

## Что реализовано в исходниках

- Открытие боковой панели нажатием на иконку расширения (Chrome 114+).
- Пользовательский запуск чтения доступного текста открытой HTTP(S)-страницы через `activeTab` + `scripting`.
- Предварительное определение предмета по заголовку, вопросу и доступному текстовому контексту; ручной выбор предмета.
- Редактируемые поля вопроса и вариантов ответа, копирование в буфер обмена и переход на платформу с поисковым запросом.
- Сохранены быстрые ссылки на разделы MEDBIOHIM.
- Расширение не получает cookies/history, не извлекает токены и не отправляет извлечённые вопросы автоматически.

## Установка для теста

1. Откройте `chrome://extensions` (Chrome) или `edge://extensions` (Edge).
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку `integrations/browser-extension`.
5. Откройте обычную страницу теста и нажмите на иконку расширения. Нажмите «Считать вопрос со страницы», проверьте текст и предмет.

## Разрешения

- `activeTab`: временный доступ к активной вкладке после действия пользователя.
- `scripting`: извлечение видимого текста и вариантов только по запросу пользователя.
- `sidePanel`: отображение компактного интерфейса рядом с текущей страницей.
- Host permissions не запрашиваются. Содержимое страницы не передаётся автоматически на сервер.

## Известные ограничения — следующие этапы

- Определение предмета пока эвристическое и требует ручной проверки; список предметов будет связан с реальным каталогом MEDBIOHIM.
- Универсальный DOM-анализатор не гарантирует распознавание всех LMS и видов тестов. Для популярных источников нужны проверенные адаптеры.
- Кнопка поиска открывает платформу с текстом запроса, но не выполняет поиск напрямую из расширения: защищённый API требует пользовательской авторизации и ещё не подключён к панели.
- Ответы, сохранение кандидатов, чтение результата завершённого теста, доверенный список источников и журнал модерации ещё не подключены. Ничего не импортируется автоматически.
- Перед выпуском обязательны проверки на реальных страницах, доступность/авторизация, валидация всех маршрутов и тесты. GitHub Actions ранее не запускал шаги; CI нельзя считать зелёным до фактического выполнения.

## Безопасность

- Не хранит пароль, сессионный токен, ключ Supabase или Telegram token.
- Не читает историю браузера и не использует cookies API.
- Не обходит авторизацию, paywall или технические ограничения сторонних сайтов.
- Любой будущий импорт должен проходить через защищённый API с серверной проверкой прав, идемпотентностью, источником и статусом доверия.
- Это независимый optional-инструмент; его отсутствие не влияет на основной сайт.
