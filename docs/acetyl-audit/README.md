# Аудит acetyl.ru — «сайт по химии Виктора Абрамова»

> Дата: 16.11.2026. Проверено вживую: главная, сборник задач, справочник (метан), графический редактор, калькулятор (запрос «метан 16 грамм»), таблица Менделеева, таблица растворимости. Скриншоты: `../sechenova-cabinet/screens/40-acetyl-trainers.png` … `45-acetyl-solubility.png`.

## 1. Что это

Не курс и не «платформа», а **инструментальный сайт по химии** с очень сильной поисковой и задачной частью:

- **Сборник задач и тренажёров** — десятки тренажёров, привязанных к номерам ЕГЭ.
- **Химический справочник** — карточки веществ + база реакций.
- **Графический редактор** — рисование структурных формул с распознаванием.
- **Химический калькулятор** — расчёты по запросу на естественном языке.
- **Таблица Менделеева**.
- **Таблица растворимости** + ряд активности металлов.

Пользователь: школьник/студент, который готовится к ЕГЭ по химии и решает задачи. Ценность — **мгновенный ответ на конкретный вопрос**, а не «пройти курс».

## 2. Сборник задач и тренажёров

Открывается из меню. Внутри:

- Заголовок «Тренажеры по химии Acetyl».
- Переключатели: **Органическая химия** / **Неорганика и общая химия**; **Номера ЕГЭ**; **Мои результаты**.
- Баннер: «Вы не авторизованы на сайте. Чтобы ваши успехи сохранялись… пройдите упрощённую авторизацию» + кнопка «Авторизоваться».
- **Тренажёры сгруппированы по номерам заданий ЕГЭ:**
  - Задача 1 — «Электронные конфигурации»;
  - Задача 2 — «Периодический закон»;
  - Задача 3 — «Степени окисления»;
  - Задача 4 — «Кристаллические решётки, хим. связи»;
  - Задача 5 — «Классы неорганики»;
  - Задача 6 — «Обменные реакции»;
  - Задача 7 — «Поиск реагентов»;
  - Задача 8 — «Подбор продуктов реакции»;
  - Задача 9 — «Мини-цепочка, неорганика»;
  - Задача 10 — «Органика. Классификация»;
  - Задача 19 — «Изменение ст. ок. в ОВР»;
  - Задача 21 — «Гидролиз, среда раствора»;
  - Задача 31 — «Неорганические цепочки».
- В каждой группе — 4–7 тренажёров («Тренажер 1…5», «Жесть», «Редкие реакции ЕГЭ прошлых лет»), по 8–20 задач.
- **Статус каждого тренажёра:** «не решали» / «результат последней попытки 73%» / «недавно» (повторная попытка не засчитывается) / сложность / число задач.
- Кнопка «Показать все» для длинных групп.
- **Легенда обозначений** — отдельный блок с объяснением иконок.
- **Рандомные задачи:** «Весь курс школьной химии» (2000 задач), «Вся неорганика» (1000), «Вся органика» (1000).
- **Обратная связь:** лайк/дизлайк задачам, «Сообщить об ошибке» под каждой задачей.
- Пояснение автора: собирает статистику, чтобы ранжировать задачи по сложности; признаёт, что сложность пока «прикидочная».

**Паттерн:** контент жёстко привязан к **экзаменационным номерам**, а не к главам учебника. Студент сразу видит «Задание 29 — ОВР» и тренирует именно его.

## 3. Главная страница = случайная задача

На главной — не лендинг, а **сразу задача** из «Весь курс химии»:

- «Задача 1287. Весь курс химии».
- Условие: «Предскажите ход реакции и уравняйте её».
- Картинка с реакцией.
- Подсказки: учитывать условия, коэффициенты; ответ — продукты через «+» с коэффициентами; если реакция не идёт — «не идет».
- Поле ввода ответа + кнопка «1» (попытка).
- «Выбрать рубрику», «Следующая задача».
- «Проверить ответ и показать решение».
- Шаринг (Telegram, VK, OK, копировать ссылку), «Сообщить об ошибке».
- Ссылка «Все задачи» и копирайт.

**Паттерн:** нулевой барьер входа. Не «зарегистрируйтесь», а «вот задача — попробуйте». Это лучший онбординг для учебного инструмента.

## 4. Химический справочник

Огромное дерево:

- **Органические вещества / Неорганические вещества** (переключатель).
- «Алфавитный указатель реакций органической химии».
- Разделы: Углеводороды (алканы, циклоалканы, непредельные, алкадиены, алкины, ароматические), Номенклатура радикалов, Кислородсодержащие (спирты, альдегиды, кетоны, карбоновые кислоты, производные), Азотсодержащие (амины), Сераорганические, Углеводы.
- У каждого класса — карточка с картинкой, коротким описанием и ссылками: **Общая статья, Номенклатура, Химические свойства, Получение**.
- Внутри класса — конкретные вещества (метан, этилен, ацетилен, толуол, этанол, ацетальдегид, ацетон, уксусная кислота, глюкоза…).

### Карточка вещества (проверено на «Метан»)

- Инфобокс: предложенное название, синоним («болотный газ»), класс, молярная масса, брутто-формула, t° плавления/кипения, внешний вид, «Показать массовые доли элементов».
- Структурная формула (картинка).
- Описание: нахождение, получение, применение, безопасность.
- **Реакции по типам:** галогенирование, реакция Коновалова, каталитическое окисление, паровая конверсия, термическое разложение, сульфохлорирование, горение, фотолиз.
- У каждой реакции: заголовок, картинка уравнения, кликабельная строка «метан + бром → (hν) → бромметан + бромоводород», ссылки на реагенты/продукты, «Подробнее», ID реакции (`r011`), кнопка `≡` — «показать больше аналогичных реакций».
- **Блок «Тренажёры и сборники задач по теме»** — прямые ссылки на «Алканы 1…5», «Алканы и циклоалканы» с количеством задач.
- SEO-блок «Перенаправления» — десятки вариантов запросов с опечатками и транслитерацией («метин + пропан», «vtnfy + ch3-ch2-ch3»), чтобы человек попадал на страницу из поиска.
- Ссылка на Wikipedia, шаринг, «Сообщить об ошибке».

**Паттерн:** страница вещества — это **хаб**: свойства → реакции → тренировка. Всё связано перекрёстными ссылками. Плюс мощная SEO-машина на вариантах запросов.

## 5. Графический редактор

- Сетка 34×14 («коснитесь клетки, чтобы начать рисовать молекулу»).
- Инструменты: удалить атом/связь, дополнительные связи (кратные/циклы), атомы C, O, N, S, F, Cl, Br, I, Na, K; «✓» (распознать), «Отменить», «Очистить», «Справка».
- Шаблоны: бензол, циклопропан, циклобутан, циклопентан, циклогексан, циклогептан, циклооктан, нафталин, карбонильная, карбоксильная, амидная, гидропероксигруппа, нитро-, сульфо-, нитратная, сульфатная, фосфатная группы.
- Проверено: клик по шаблону «Бензол» рисует молекулу, и под полем появляется подпись **«Бензол»** — то есть редактор распознаёт структуру и называет вещество.
- «Копировать ссылку» — можно поделиться нарисованной формулой.

**Паттерн:** сложный ввод (структурная формула) заменён на «рисуй пальцем/мышью», а система сама называет вещество. Это резко снижает барьер по сравнению с вводом SMILES.

## 6. Химический калькулятор

Отдельная страница-справка «Что умеет сайт», но **сам калькулятор — это строка поиска вверху**. Запросы на естественном языке, по-русски.

Умеет:

1. Количество вещества по массе: «метан 16 грамм» → показывает «Введённая масса 16 г», «Количество вещества 1 моль».
2. Массу и количество компонента по массе смеси и массовой доле: «серная кислота 49 грамм 20%».
3. Массы продуктов и остальных реагентов по массе одного реагента; можно указать только два реагента — программа сама допишет уравнение и расставит коэффициенты.
4. Определение реагента в избытке и массу избытка по массам двух реагентов.
5. Массовые доли элементов в молекуле — через «Показать массовые доли элементов».
6. Определение простейшей формулы и возможных веществ по массовым долям: запрос начинается со слова «состав», например «состав C 52,2%, H, O»; до 20 веществ; умеет достраивать недостающую долю и работать с округлениями.
7. Проверку, уравнена ли реакция: если коэффициенты неверны — красный восклицательный знак, если верны — зелёная галочка.

Правила синтаксиса: название в именительном падеже, масса словом «грамм» (не «г»), проценты со знаком «%», без знаков препинания, порядок «вещество → масса → доля».

**Паттерн:** один input, который понимает химический русский. Не формы с 10 полями, а «напиши как думаешь». Это killer-feature для школьников.

## 9. Сильные стороны (что брать)

1. **Мгновенная польза без регистрации.** Главная — задача, а не лендинг.
2. **Привязка к номерам ЕГЭ.** Понятная навигация для школьника.
3. **Три уровня глубины на одной странице:** кратко (карточка) → реакции → тренажёр.
4. **Естественно-языковой калькулятор** — уникальная фича, снимает барьер ввода.
5. **Графический редактор с распознаванием** — ещё одна уникальная фича.
6. **SEO-машина:** страницы под сотни формулировок и опечаток, перелинковка вещество ↔ реакция ↔ тренажёр.
7. **Обратная связь:** лайк/дизлайк, репорт ошибки, статистика сложности.
8. **Статус тренажёра:** результат, «недавно», сложность, число задач — видно, что делать дальше.

## 10. Слабые стороны (что не копировать)

1. **Устаревший/перегруженный UI:** таблицы, вёрстка 2010-х, реклама, «SAPE»-блоки, местами сломанные iframe.
2. **Нет нормального онбординга и прогресса** без «упрощённой авторизации»; результаты теряются.
3. **Много текста и SEO-мусора** внизу страниц (сотни «перенаправлений»), это мешает человеку.
4. **Нет мобильного сценария** как первого класса: редактор и таблицы рассчитаны на мышь.
5. **Нет объяснения «почему ответ такой»** в задаче на главной, пока не нажмёшь «Показать решение».
6. **Дублирование сущностей** (вещество/реакция/рубрика) без единой модели.

## 11. Что перенести в «Изучай»

- **Принцип «главная = действие»:** сразу карточка/задача, без лендинга.
- **Привязка контента к экзаменационным номерам/темам**, а не к абстрактным главам.
- **Карточка сущности как хаб:** свойства → связи → практика.
- **Естественно-языковой ввод** для расчётов и поиска (на русском).
- **Мини-редактор/конструктор** для сложных схем (формулы, реакции, препараты) с распознаванием.
- **Статусы и результаты** прямо на карточке тренировки.
- **Обратная связь по контенту** (лайк/дизлайк/репорт) с влиянием на выдачу.
- **SEO-слой** — но аккуратно: один канонический URL + человеческая навигация, без сотен мусорных редиректов.

## 12. Вывод

Acetyl — это **инструмент**, а не «продукт с вовлечением». Его сила — в плотности пользы на квадратный пиксель: задача, формула, расчёт, таблица. Для «Изучай» это источник паттернов «быстро, точно, по делу», но не источник дизайна и не источник монетизации (её там почти нет).
