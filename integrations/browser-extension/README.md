# MEDBIOHIM Bridge — браузерное расширение

Chrome/Edge Manifest V3. Версия 0.3.0 добавляет к боковой панели сбор вопросов и ручную подготовку JSON для preview-импорта в MEDBIOHIM. Расширение по-прежнему не делает прямых API-вызовов из панели: пользователь скачивает JSON или копирует его и вставляет на странице `/university/import`.

## Что реализовано в исходниках

- Открытие боковой панели нажатием на иконку расширения (Chrome 114+).
- Пользовательский запуск чтения доступного текста открытой HTTP(S)-страницы через `activeTab` + `scripting`.
- Предварительное определение предмета по заголовку, вопросу и доступному текстовому контексту; ручной выбор предмета.
- Редактируемые поля вопроса и вариантов ответа, доступные подписи изображений и отдельное поле формул/уравнений; извлечение доступного MathML/KaTeX/MathJax/ARIA/data-math текста, копирование и поиск с контекстом.
- Поля «Тест / источник», тип вопроса, правильные номера и эталонный открытый ответ.
- Набор вопросов: добавление, удаление, счётчик, стабильный `question_key`, скачивание JSON и копирование для вставки в `/university/import`.
- В JSON сохраняются source metadata: система, URL, название теста, время сбора и способ `user-marked-correct`.
- Сохранены быстрые ссылки на разделы MEDBIOHIM.
- Расширение не получает cookies/history, не извлекает токены и не отправляет извлечённые вопросы автоматически.

## Установка для теста

1. Откройте `chrome://extensions` (Chrome) или `edge://extensions` (Edge).
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку `integrations/browser-extension`.
5. Откройте обычную страницу теста и нажмите на иконку расширения. Нажмите «Считать вопрос со страницы», проверьте текст и предмет.

## Сбор теста и импорт

1. Откройте тест в оригинальной системе в своей браузерной сессии.
2. Считайте вопрос, проверьте текст и варианты.
3. Укажите правильные номера (например, `1` или `1,3`) либо эталонный открытый ответ.
4. Нажмите «Добавить в набор» и повторите для нужных вопросов.
5. Скачайте JSON или скопируйте его и откройте `/university/import`.
6. Вставьте/загрузите JSON, выберите предмет, проверьте preview и выполните `dry_run`/импорт.

Импорт доступен только администратору MEDBIOHIM через существующий `POST /admin/content/import`. Повторный импорт обновляет записи по стабильным `source_key`; по умолчанию тест и вопросы сохраняются неопубликованными.

## Разрешения

- `activeTab`: временный доступ к активной вкладке после действия пользователя.
- `scripting`: извлечение видимого текста и вариантов только по запросу пользователя.
- `sidePanel`: отображение компактного интерфейса рядом с текущей страницей.
- Host permissions не запрашиваются. Содержимое страницы не передаётся автоматически на сервер.

## Известные ограничения — следующие этапы

- Определение предмета пока эвристическое и требует ручной проверки; список предметов будет связан с реальным каталогом MEDBIOHIM.
- Распознавание использует несколько стратегий DOM-поиска, но не гарантирует распознавание всех LMS и видов тестов. Нестандартные iframe, изображения/PDF и закрытые браузерные страницы могут требовать отдельного адаптера, ручного копирования или будущего OCR. Текущий шаг собирает только доступные текстовые подписи к изображениям (alt/ARIA/title/figcaption); он не распознаёт содержимое пикселей, стрелки, микропрепараты, графики или текст внутри изображения. Формульный сбор не восстанавливает произвольные структурные формулы, стереохимию или знаки, потерянные при отрисовке. Не делается автоматическая отправка картинок на внешний OCR/ИИ. Расширение не обходит CAPTCHA, авторизацию, paywall, антибот-защиту или запреты доступа; оно работает только с доступным пользователю содержимым.
- Кнопка поиска открывает платформу с текстом запроса. На странице поиска теперь можно раскрыть сохранённый ответ для опубликованных вопросов/билетов, если сервер вернул его и пользователь авторизован. Это промежуточный этап: прямой поиск и показ результата внутри самой панели ещё не подключены.
- Прямой ответ в панели, чтение результата завершённого теста, доверенный список источников и журнал модерации ещё не подключены. Набор вопросов хранится только в памяти панели до скачивания/копирования; в MEDBIOHIM ничего не импортируется автоматически.
- Перед выпуском обязательны проверки на реальных страницах, доступность/авторизация, валидация всех маршрутов и тесты. GitHub Actions ранее не запускал шаги; CI нельзя считать зелёным до фактического выполнения.

## Безопасность

- Не хранит пароль, сессионный токен, ключ Supabase или Telegram token.
- Не читает историю браузера и не использует cookies API.
- Не обходит авторизацию, paywall или технические ограничения сторонних сайтов.
- Любой будущий импорт должен проходить через защищённый API с серверной проверкой прав, идемпотентностью, источником и статусом доверия.
- Это независимый optional-инструмент; его отсутствие не влияет на основной сайт.
