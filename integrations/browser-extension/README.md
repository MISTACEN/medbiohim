# MEDBIOHIM — браузерное расширение

Минимальный MVP быстрого доступа к официальным разделам MEDBIOHIM для Chrome и Edge (Manifest V3).

## Установка для теста

1. Откройте `chrome://extensions` (Chrome) или `edge://extensions` (Edge).
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку `integrations/browser-extension`.
5. Закрепите расширение на панели и проверьте все ссылки.

## Безопасность

- Расширение не запрашивает permissions и host permissions.
- Не хранит пароль, токен сессии, ключ Supabase или Telegram token.
- Не читает страницу, историю браузера или введённые пользователем данные.
- Открывает разделы на официальном домене; авторизация выполняется только самим сайтом.
- Это независимый optional-инструмент: его отсутствие не влияет на основной сайт.

## Ограничения MVP

- Это панель быстрых ссылок, а не замена мобильного сайта.
- Прямой API-доступ, фоновые уведомления, синхронизация и работа с приватными данными не реализованы.
- Перед публикацией нужно проверить все маршруты на production, а затем подготовить иконки, скриншоты, privacy disclosure и браузерные пакеты.
