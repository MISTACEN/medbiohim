# Рабочие копии и ветки MEDBIOHIM

## Каноническая ветка

`main` — единственная каноническая ветка и источник истины для согласованной разработки и production. Начинай задачу с актуального `main` и точного base SHA.

## Параллельная работа без постоянных веток

Обычный процесс для нескольких ИИ-агентов:
1. Каждый агент получает отдельную копию репозитория или отдельный локальный git worktree от одного base SHA.
2. Writable directory между агентами не разделяется.
3. Агент не создаёт постоянную remote branch, не пушит и не открывает PR по умолчанию.
4. Каждый возвращает patch/diff и отчёт.
5. После завершения независимых задач координатор выбирает одного интегратора; он применяет patch последовательно в отдельной integration workspace.
6. После QA/review maintainer разрешает один последовательный commit непосредственно в `main`.

Нельзя двум агентам одновременно менять один файл или писать в общий `main` checkout. При конфликте назначается один writer; второй делает read-only review.

## Существующие ветки

В GitHub могут оставаться `beta`, `backup/*`, `feat/*`, `fix/*` и другие исторические ветки. Сам факт существования не делает их актуальными, защищёнными или готовыми к merge. Перед использованием сравни их с текущим `main` и проверь владельца/назначение. Не удаляй их автоматически.

`beta` не является обязательной частью текущего процесса и не используется как постоянный промежуточный этап для каждой задачи. Создание новой remote branch допускается только по отдельному явному решению пользователя/maintainer.

## Commit и release

- Не force-push и не переписывай чужую историю.
- Перед commit проверь чистоту дерева, base SHA, `git diff --check`, изменённые пути и релевантные тесты.
- До push изучи `.github/workflows/**`, Vercel Git integration и path filters: commit может запускать CI/deployment.
- Не запускай production deploy, workflow_dispatch, миграцию или secret changes без отдельного разрешения.
- Commit в `main`, CI, deployment и production smoke — четыре разных статуса; сообщай каждый только при наличии доказательства.
