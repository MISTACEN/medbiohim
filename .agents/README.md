# MEDBIOHIM agent workspace

Это repo-level operating model для внешних ИИ-агентов и субагентов. Он не устанавливает агентный runtime и не означает, что агенты уже запущены.

- `coordinator.md` — координатор/архитектор.
- `agents/frontend.md`, `backend.md`, `database.md`, `education.md`, `storage.md`, `devops.md`, `qa-security.md` — инструкции по ролям.
- `education-subagents.md` — предметные субагенты Education.
- Корневой `AGENTS.md` обязателен для всех.

## Запуск задачи
Координатор формирует один Task Brief по `AGENT-TASK-PROTOCOL.md`, назначает владельца каждого файла и выдаёт каждому исполнителю отдельный workspace. Субагенты не коммитят в общий `main`. Координатор интегрирует изменения последовательно после независимого QA.

## Совместимость
Названия директорий сверены с main на 2026-11-03. Если путь отсутствует в текущем checkout, агент должен сначала найти реальный путь, а не создавать дубликат по предположению.

## Режимы команды
Смотри `AGENT-OPERATING-MODES.md`: от одного агента без субагентов до двух ведущих агентов с двумя субагентами у каждого. Субагенты включаются по необходимости, а не автоматически.
