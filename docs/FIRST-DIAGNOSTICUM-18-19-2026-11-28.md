# «Первая диагностика»: 18 или 19 позиций (разбор)

Дата: 2026-11-28. Вопрос из концепции §8: набор назван «18 позиций», а перечень
содержит 19 имён. Проверка показывает, что **это арифметическая ошибка в
документе, а не лишняя позиция в банке**: список сходится сам с собой, и все 19
позиций обеспечены методичками.

## Перечень концепции §8 и его счёт

| Раздел | Позиции | Кол-во |
|---|---|---|
| Цитология | Жировые включения; митоз | 2 |
| Эмбриология | Сперматозоиды; яйцеклетка; осевые органы | 3 |
| Эпителии | Цилиндрический (тонкая кишка); мерцательный (трахея); многослойный плоский неороговевающий (роговица); переходный (мочевой пузырь) | 4 |
| Соединительные и хрящевые | Кровь — мазок; сухожилие; гиалиновый хрящ; эластический хрящ | 4 |
| Костные и мышечные | Трубчатая кость (диафиз); развитие кости на месте мезенхимы; поперечно-полосатая скелетная мышечная ткань | 3 |
| Нервная | Миелиновые нервные волокна; астроцитарная глия; пластинчатое тельце | 3 |
| **Итого** | | **19** |

Ни одна пара в перечне не выглядит «одной позицией, записанной дважды»: все
названия — разные препараты с разными методичками. Поэтому «18» не может быть
результатом склейки двух имён.

## Что в коде

`workers/api/src/routes/diagnosticum/sets.ts` — `FIRST_DIAGNOSTICUM` содержит
ровно 19 позиций с номерами из перечня:

```
1.1 cytology-fat-inclusions        4.1 ct-blood-smear
1.2 cytology-mitosis               4.2 ct-tendon
2.1 embryology-sperm               4.3 ct-hyaline-cartilage
2.2 embryology-egg                 4.4 ct-elastic-cartilage
2.3 embryology-axial-organs        5.1 bone-tubular
3.1 epithelium-columnar-intestine  5.2 bone-development
3.2 epithelium-ciliated-trachea    5.3 muscle-striated
3.3 epithelium-nonkeratinized-cornea 6.1 nerve-myelin
3.4 epithelium-transitional-bladder  6.2 nerve-astrocytes
                                     6.3 nerve-pacinian
```

Счёт по разделам совпадает с таблицей выше (2/3/4/4/3/3), лишних или
недостающих ключей нет.

## Пропуски методичек

`setGuides` возвращает отсутствующие ключи в `missing`, и обзор показывал
«18 из 19», пока у `embryology-axial-organs` не было разбора. 19-я методичка
добавлена 2026-11-26 (аудит §19), после этого обзор отдаёт «Первая диагностика ·
19» без пометки «из» — то есть `missing` пуст. Механизм `missing` остаётся: если
методичку уберут, набор честно покажет неполноту, а не подменит позицию.

## Решение

1. Набор остаётся **19 позиций** — сокращать его нельзя: концепция прямо
   запрещает самостоятельно удалять или объединять позиции.
2. Формулировку «18 позиций» в концепции считать опечаткой; в коде и в обзоре
   используется фактическое число.
3. Если появится внешнее требование «ровно 18» (например, из учебного плана),
   решение о том, какую позицию убрать, принимает человек — в коде для этого
   достаточно удалить строку из `FIRST_DIAGNOSTICUM.items`, но это отдельное
   согласование, а не техническая правка.

## Проверка

- `GET /api/v1/diagnosticum` → раздел «Первая диагностика» с `total: 19`,
  без `missing` (проверено в проде 2026-11-28).
- `vitest`/`workers-api` покрывают `setGuides` и `isSetSection` (тесты
  диагностикума).
