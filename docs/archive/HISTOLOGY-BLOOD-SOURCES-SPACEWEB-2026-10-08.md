# Источники крови и учебники SpaceWeb — 2026-10-08

## Каноническая схема

Физические файлы гистологии хранятся на SpaceWeb:

/public_html/content/histology/

Для учебников используется:

content/histology/source-materials/Учебники/

Supabase остаётся слоем метаданных и связей предмета; сами новые PDF-учебники в БД не дублируются.

## Кровь

Практическая связка на сайте:

реальное фото препарата → куда смотреть → морфологические признаки → функция → чем не перепутать → самостоятельный ответ → разбор

Основой являются:
- 4.Кровь.docx;
- дополнительная учебная памятка с алгоритмом распознавания и морфологическими описаниями;
- существующие фотографии препаратов из каталога 5_Фотографии препаратов.

## Фотографии

В рабочем тренажёре используются только подтверждённые существующие trainer-карточки:
- feed-prep-867b72a4b6 — нейтрофил;
- feed-prep-a47e9dc83a — эозинофил + нейтрофил;
- feed-prep-5a224c48f5 — лимфоцит;
- feed-prep-bca30caf3b — моноцит;
- feed-prep-a2feb3ec86 — лимфоцит + моноцит;
- feed-prep-60e72c3e7e — тромбоциты.

Сравнительные изображения не используются как неоднозначные single-cell задания.

## Учебники

Backend:
- GET /api/v1/histology/source-materials?folder=Учебники — список PDF из SpaceWeb;
- GET /api/v1/histology/source-file?path=Учебники/<имя>.pdf — защищённая выдача конкретного PDF.

Frontend:
- вкладка «Учебники» в материалах гистологии;
- исходное имя файла показывается без переименования;
- PDF открывается встроенным viewer;
- доступно скачивание текущего PDF.

## Atlas

В материалах есть описания, которые опираются на атласный учебный контекст. При этом отдельные физические atlas-изображения с однозначной разметкой в предоставленных архивах не были выделены как самостоятельные файлы. Поэтому код не выдаёт сгенерированные схемы или фотографии за изображения атласа.
