# Карта фич: «взять всё по максимуму» и как это собрать

> Каждая фича трёх сайтов → максимальная версия → способ самостоятельной реализации → open-source → оценка.
> Оценка: **S** ≤ 1 недели, **M** 1–4 недели, **L** 1–3 месяца, **XL** 3+ месяца (для одного разработчика).
> Платные фичи помечены `✂` — не переносим по условию.

## 9. Что не делаем (`✂`)

- подписки, пейволы, платный доступ к темам;
- магазин токенов за деньги, платные ИИ-кредиты;
- «Клинреки Pro», «Наследие», «Ускоритель»;
- реферальные деньги и вывод;
- каталог с корзиной и оплатой;
- «товар дня −40%» и скидки за демо.

Вместо них: бесплатный доступ, честные лимиты ИИ, «поделиться» без вознаграждения.

## 10. Волны внедрения (если брать всё)

### Волна 1. Петля (4–6 недель)
Карточка дня, SRS, 300–500 вопросов, слабые темы, прогресс, Telegram, онбординг, аналитика.

### Волна 2. Контент и практика (6–10 недель)
Предметы/темы, практика, фильтры, тренажёры, экзамен/план, поиск, уведомления.

### Волна 3. ИИ и химия (8–12 недель)
ИИ-тьютор с RAG и цитатами, 5 генераторов, Ketcher, RDKit, таблицы, калькулятор.

### Волна 4. Симуляции (8–16 недель)
5–10 сцен, пошаговые опыты, тренажёры после сцен.

### Волна 5. Социальное и полная геймификация (8–12 недель)
Лента достижений, комментарии, друзья, лига, дерево, магазин (без денег), колесо.

### Волна 6. Платформа (6–10 недель)
PWA, приложение, тёмная тема, языки, резервные копии, модерация, A/B.

**Итого:** 6–12 месяцев для 1–2 человек, если делать всё и качественно. Быстрее — только за счёт готовых LMS/H5P и отказа от части симуляций.

## 11. Что не надо делать самому

- 3D-анатомию с нуля — Z-Anatomy/BodyParts3D.
- Видеотранскодинг — Cloudflare Stream/Mux.
- Модель ИИ — API/Ollama.
- Платёжку — не делаем.
- Полный LMS — Moodle/Frappe, если нужны ведомости.
- 78 симуляций — 5–10 ключевых.

## 12. Мини-чек-лист «взяли всё»

- [ ] У каждой фичи есть владелец и метрика.
- [ ] Ни одна фича не ломает петлю «карточка → ответ → повторение».
- [ ] Контент проверен человеком.
- [ ] ИИ не выдумывает факты без пометки.
- [ ] Нет платных фич.
- [ ] Есть план отката/удаления фичи, если метрика не выросла.
