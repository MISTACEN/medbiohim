# Полная концепция платформы Медбиохим

> Источник правды по продуктовой модели. Ветка сверки: **`beta`**.

## Единица работы

**Предмет + Курс + Семестр**  
Пример: `Биохимия · 2 курс · Осенний семестр`.

К этой связке привязаны: учебный план, билеты и вопросы, лекции, материалы (конструктор), общие и личные карточки SRS, прогресс.

Студент почти всегда работает **внутри текущего предмета**.

## Боковое меню (короткое)

Главная, Поиск, Расписание, Предметы, Задания, Прогресс, Сообщество, Калькуляторы, AI-тьютор, Настройки, Помощь, Админ.

**Не в меню** (живут на странице предмета): Лекции, Билеты, Практика, Материалы, Карточки SRS, Учебный план, Тесты.

## Страница предмета `/subjects/[id]`

Блоки: план, билеты, практика, лекции, материалы, SRS (общие/личные), прогресс.

## Копирование семестра

Копируется структура (план, разделы, материалы, общие карточки).  
**Не копируются** личные карточки и прогресс. Опционально — предложить студентам перенос личных карточек.

## Роли

- **Студент** — свои предметы, только личные карточки
- **Преподаватель** — предметы своих групп
- **Админ** — полный конструктор + clone semester
- **Гость** — ограниченный preview
