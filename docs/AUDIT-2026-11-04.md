## 6. Что сделано в этот проход (этапы A и ядро B/G)

### Общая образовательная модель

- `src/lib/learning/types.ts` — единая модель: уровни пирамиды (база /
  понимание / применение), типы активностей (12), атрибуция источника
  (научный факт / учебная модель / упрощённая симуляция / предположение /
  непроверенный материал), контракт предметного адаптера, проекция прогресса.
- `src/lib/learning/subjects.ts` — адаптеры для реальных slug
  (`physiology`, `histology`, `chemistry_organic_physical`,
  `inorganic_chemistry`, `biology`), список возможностей и безопасный
  fallback для неизвестного предмета.
- `src/lib/learning/grading.ts` — детерминированная проверка: один/несколько
  ответов, верно-неверно, число с абсолютным и относительным допуском,
  короткий ответ, формула (с подстрочными индексами), последовательность
  (частичный зачёт по LCS), сопоставление, открытый ответ по смысловым
  элементам с весами и порогом. Оценка не зависит от AI.
- `src/lib/learning/srs.ts` — SM-2 с той же математикой, что в Worker
  (`workers/api/src/routes/srs.ts`), но с явной датой отсчёта для
  воспроизводимости; плюс объяснение причины повторения.

### Движок симуляций

- `src/lib/sim/types.ts`, `src/lib/sim/engine.ts` — контракт
  «сцена/параметры/шаги/измерения/график/проверка», валидация и обрезка
  параметров, безопасный расчёт, построение кривой.
- `src/lib/sim/catalog.ts` — три самостоятельные модели:
  - кинетика фермента (Михаэлис–Ментен + конкурентное ингибирование);
  - титрование слабой кислоты (pH из уравнения электронейтральности,
    а не только из приближения Гендерсона–Хассельбаха);
  - мембранный потенциал покоя (Гольдман–Ходжкин–Кац, 37 °C).
  У каждой — допущения, ограничения, источник и проверка понимания.
- `src/app/labs/simulations/page.tsx` +
  `src/components/labs/SimulationRunner.tsx` — рабочая страница: ползунки
  параметров, измерения, график, пошаговое объяснение, проверка понимания,
  блок «что модель не учитывает».

### База данных

- `database/migrations/20261104_knowledge_pyramid.sql` — **аддитивная**
  миграция: `topics.knowledge_level`, `materials.knowledge_level`,
  `materials.source_attribution jsonb`, CHECK 1–3, частичные индексы,
  комментарии. RLS и права не менялись, backfill не выполнялся.
- Применена в `gnobvyjywtqbdfeejxmf` как `20261104_knowledge_pyramid`
