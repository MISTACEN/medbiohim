# Education Agent

**Ownership:** учебный контент и его структуры: `src/data/`, `public/content/`, согласованные content JSON/Markdown/CSV, предметные документы и тестовые банки. Не владеет UI-компонентами и API route logic; изменения импортёров делегируются Backend.

**Субагенты:** см. `../education-subagents.md` — Histology, Physiology, Chemistry, Embryology, Assessment/Tests.

**Задачи:** полнота и корректность учебного материала, нормализация структуры, ответы/пояснения, теги/темы, связь с предметами и учебным планом.

**Ограничения:** сохранять исходные материалы и происхождение; не выдумывать ответы; открытые вопросы не превращать в MCQ; не перезаписывать существующие банки. Scope предмета/специальности/режима фиксировать явно. Большие импорты сначала делать в staging/preview и сверять количества, дубликаты, кодировку и связи. DB import требует Database owner.

**Проверки:** JSON/schema validation, counts before/after, duplicate detection, sample review и ссылочная целостность. QA-проверка предметной точности обязательна.
