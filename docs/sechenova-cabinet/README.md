## 0. Как устроен кабинет

- **Два кабинета на одном домене.**
  - Новый: `/teach/cabinet` — SPA с hash-роутингом (`#/today`, `#/study`, …). Основной интерфейс.
  - Старый: `/teach/cabinet?ui=old` — отдельная вёрстка с другим меню, Pomodoro, переключателем языка и т.п. Переключатель «Старый кабинет» / «Новый кабинет» есть в обоих.
- **Верхняя навигация нового кабинета:** Сегодня · Учёба · Практика · Лента · Спросить ИИ · Создать с ИИ · Профиль. Блок «ЕЩЁ»: Сообщество, Наследие, Ускоритель, Пригласить друзей, Старый кабинет. Справа — поиск (`Ctrl K`), уведомления, аватар.
- **Боковая колонка «ВЫ ПОЛЬЗУЕТЕСЬ»** динамическая: показывает последние посещённые разделы (на разных страницах — разные пункты: Лига, Серия, Цели, Дерево навыков, Экзамен, План, Шпаргалки, Друзья…). Это фактически «недавнее».
- **Сквозные счётчики в шапке:** серия дней (0), токены (120), место в лиге (#2).
- **SPA на hash-роутах**, контентные страницы — обычные URL (`/courses`, `/spravochnik`, `/teach/cards`, `/teach/video`, `/trainer/...`).
- **Геймификация — ядро продукта:** токены, серия, лига, квесты, дерево навыков, колесо, сундук, коллекция значков, магазин, рефералка.

### 2.6. Создать с ИИ (`#/create`)

**Верхний блок «Конспект из материала»:** «Загрузить файл или фото», «Записать лекцию», «По ссылке» (`/teach/kit`). Счётчик «Конспекты в этом месяце 0 из 2».

**Группа «Конспекты и карточки»:**
- Набор по ссылке (`/teach/kit`) — статья/документ/видео → конспект, уроки как в Duolingo и карточки.
- Мои учебники (`/teach/kit?books=1`) — учебник целиком → набор по главам.
- Карточки из лекции (`/teach/lecture-cards`) — слайды/фото → короткие уроки с вопросами.
- Карточки к экзамену (`/teach/lecture-cards#/exam`) — предмет, дата, вуз → уроки по дням.

## 3. Сквозные механики (то, что нужно проектировать, а не копировать по кнопкам)

### 3.1. Токены
- **Заработок:** квесты (+10…+20), день учёбы (+5), очки лиги 1:1 (до +20/день), вехи серии (+20…+1000), новый бейдж (+25), сундуки плана (+15), приветственный бонус (+100), промо.
- **Траты:** ИИ-генерации, кредиты Студии, шпаргалки, объяснения на доске, ролики, картинки, заморозка серии (120), буст лиги (200), значки коллекции (80), промокоды.
- **Ограничения:** часть товаров закрыта до порога «заработано учёбой 150 токенов»; лимиты «раз в месяц/30/90 дней»; «товар дня» меняется в полночь; нельзя купить токены деньгами (в интерфейсе не видно).
- **Прозрачность:** история начислений, «как заработать», шансы призов.

### 3.2. Серия
- День засчитывается за любое учебное действие; чтение — после 3 минут; открытие приложения не считается.
- Заморозки (0/2, +1 каждые 7 дней, покупка за 120), цель серии с бонусом, 16-недельный heatmap, вехи наград.

### 3.3. Лига
- 4 уровня, недельный цикл, топ-2 вверх / двое последних вниз, очки за действия, глобальный рейтинг, «зона повышения/понижения».

### 3.4. Квесты
- 3 слота, сложность, прогресс, реролл, «Начать», сундук за все 3, сброс по таймеру.

### 3.5. Уровни/дерево

### 3.6. Магазин/коллекция
- Товар дня, сундук со слотами, категории, коллекция 12 значков → промокод −20%, история, лимиты.

### 3.7. Рефералка
- Двухуровневая (20% + 5%), закрепление 365 дней, бонусы = рубли, вывод от 3000 ₽, QR/соцсети/бот, шаринг конспектов и методичек.

## 6. Как переносить в «Изучай»

### 6.1. Что уже есть в этом репозитории (`/study`)
`src/app/study/page.tsx` уже содержит: сводку, ИИ-план дня, таймлайн «Ближайшее», слабые места, SRS-карточку, ИИ-ассистента, план подготовки, прогресс, отработки и недельную лигу (`WeeklyLeague`). Это хороший фундамент: новые «фишки» Сеченова ложатся как надстройка, а не замену.

### 6.2. Приоритеты

**P0 — без этого «Изучай» не ощущается как продукт:**
1. Дашборд «Сегодня»: рекомендация, цели, серия, лига, экзамен, повторение.
2. Учёба: предметы → разделы → конспекты/учебники/файлы.
3. Практика: карточка дня + SRS + каталог тренажёров + фильтры.
4. ИИ-тьютор: чат, режимы, файлы, квоты, история.
5. Геймификация-ядро: токены (ledger!), квесты, серия с заморозками, лига, магазин.
6. Прогресс: точность, покрытие, память, ритм, готовность к экзамену.
7. Поиск Ctrl K и уведомления.

**P1 — сильные дифференциаторы:**
8. Дерево навыков + перки.
9. План-визард и ИИ-план по дням.
10. Шпаргалки, шкалы, клинреки (или интеграция).
11. Коллекция значков, колесо, сундук.
12. Профиль/настройки/напоминания, Telegram-бот.

**P2 — экосистема (только бесплатное):**
13. Лента/рилсы, сообщество, друзья, вызовы.
14. Рефералка — только как «поделиться с однокурсником», без денег и выплат.
15. Старое UI, Pomodoro, мультиязычность.

**Не переносим вообще (платное):** подписки на предметы, Клинреки Pro, Наследие, Ускоритель, магазин токенов, колесо/сундук за токены, платные ИИ-кредиты, вывод реферальных бонусов, каталог с оплатой. Причина: по условию проекта платных фич нет. Вместо них — бесплатные аналоги: полный доступ к базовым темам, ИИ-лимиты по честной квоте, «поделиться» без вознаграждения.

> Подробный продуктовый план — в [../izuchai-blueprint/README.md](../izuchai-blueprint/README.md): что строить в MVP, что не строить, метрики и чек-лист «не ширпотреб».

### 6.3. Принципы переноса
- **Экономика токенов — только через ledger** (иначе инфляция и абьюз). Все начисления идемпотентны по `(user, reason, period)`.
- **Квоты ИИ — на сервере**, а не в UI: 2 конспекта/мес, 300 карточек/день, лимиты тьютора.
- **Серия — по событию «учебное действие»**, а не по открытию; чтение ≥3 мин; защита от накрутки.
- **Лига — недельные снапшоты**, а не live-пересчёт; понижение/повышение в конце недели.
- **Геймификация не должна блокировать учёбу**: платный/токенный контент — косметика и ускорители, а не базовые знания.
- **Приватность:** не показывать чужие email/телефоны; в ленте — только имя/аватар и достижение; «кто сейчас онлайн» — агрегат, не список.
- **Пуш/email/Telegram** — единый центр настроек с тихими часами.

### 6.4. Быстрый MVP-план (4 итерации)
1. **Итерация 1:** дашборд + серия + квесты + токены-ledger + магазин (3 товара) + уведомления.
2. **Итерация 2:** практика (карточка дня, SRS, фильтры) + учёба (предметы/конспекты) + поиск.
3. **Итерация 3:** ИИ-тьютор + квоты + генераторы (5 самых ценных) + план/экзамен.
4. **Итерация 4:** лига + дерево навыков + коллекция/колесо + рефералка/подписки.

## 7. Технические наблюдения

- SPA на hash-роутах; контентные разделы — отдельные страницы. При переходе на `/teach/cabinet#/route` приложение может перезагрузиться и показать модалку «Сохранить прогресс» (email/телефон) — это нормальное поведение, не баг аудита.
- Лента — iframe; прямые ссылки на карточки не выводятся в DOM (только кнопки).
- Многие функции за пейволом: видеоуроки, КР Pro, предметы, Наследие, Ускоритель.
- Часть счётчиков (282 карточки, 779 КР, 9551 тема, 76 предметов) — маркетинговые/реальные данные платформы; при переносе нужен свой источник.
- «Сейчас на сайте N чел.» — социальное доказательство; формат агрегата.
- Старый кабинет хранит выбор UI (`?ui=old`) и после него новые hash-роуты открываются в старом интерфейсе, пока не вернуть «Новый кабинет».

## 8. Что не проверено

- Платные сценарии (оплата, автопродление, возврат) — не проводились.

- Мобильное приложение — только страница загрузки.

## 10. Как повторить аудит

1. Открыть `https://школасеченова.рф/teach/cabinet` под своим аккаунтом.
2. Пройти по hash-роутам из §1; для каждого — снять `main.innerText`, список `a[href]`, `button`, `input`, `role=tab`.
3. Отдельно открыть модалки: токены (`#/me?open=tokens`), колесо (кнопка в `#/quests`), уведомления (колокольчик), поиск (Ctrl K, затем Enter).
4. Контентные страницы: `/courses`, `/spravochnik`, `/teach/cards`, `/teach/video`, `/teach/social`, `/teach/invite`, `/teach/cabinet/nasledie`, `/app`.
5. Не выполнять оплату, не крутить колесо за токены, не запускать ИИ-генерации — это меняет состояние/списывает средства.
