# Домашнее задание: план занятия и расписание (2026-11-02)

Раньше ДЗ жило только внутри лекции (§ 1 «Домашнее задание»). Теперь оно
вынесено туда, где студент его ищет — в план занятия и в расписание — и
показывается коротким превью с раскрытием по клику.

## Где что лежит

| Место | Источник | Что видно |
|---|---|---|
| Расписание, карточка дня | таблица `homeworks` (`due_date`, `subject_id`, `group_id = null` → все группы) | заголовок ДЗ, превью описания, «показать полностью», отметка «выполнено» и отправка |
| План занятия (вкладка «План») | `public/content/histology/plan-semester3-2026-2027.json` → `weeks[].homework` | свёрнутый блок «Домашнее задание: <кратко>» → полный список пунктов |
| План в БД | `site_content.subject_plan:histology` → `weeks[].homework` | то же для тех экранов, что читают payload |

## Что сделано для эмбриологии

- Из лекции `hist-03-embriologiya` убран блок «§ 1. Домашнее задание» — он
  переехал в данные (в самой лекции теперь 18 блоков вместо 24).
- В `homeworks` создана запись: «ДЗ к практике 25.09 · Эмбриология: осевые
  органы и электронограммы», срок **2026-09-25** (день практики по теме,
  неделя 4 плана), кафедра гистологии, все группы.
- В план недели 4 добавлен `homework` с шестью пунктами (лекция + гл. 5,
  файлик, производные, электронограммы, схема осевых органов, подготовка к
  самостоятельной с критериями «4»/«5»).

## Как это выглядит

- В расписании: заголовок «ДЗ к практике 25.09 · Эмбриология: осевые органы и
  электронограммы», под ним превью текста (≈150 символов) и ссылка
  «показать полностью» — раскрывается полный список.
- В плане: строка «Домашнее задание: осевые органы, электронограммы, схема —
  развернуть», по клику — нумерованный список.

## Практика для остальных занятий

Схема повторяемая: на неделю — одна запись в `homeworks` (или `homework` в
неделе плана) + `homework` в статическом плане. Если ДЗ отличается по группе,
достаточно указать `group_id`, иначе `null` = для всех.
