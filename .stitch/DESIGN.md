# MEDBIOHIM — DESIGN.md

Бриф дизайн-системы для Stitch и для реализации в Next.js. Источник истины —
токены `src/app/globals.css` и `tailwind.config.ts`; этот файл их описывает, а не
заменяет. При расхождении прав код.

## Продукт и аудитория

Личный студенческий проект «от студентов для студентов»: подготовка к занятиям,
тесты, микропрепараты, химия. Пользователь — студент на телефоне между парами и
на ноутбуке вечером. Приоритет — быстро найти нужное и сразу начать, а не
разглядывать витрину.

## Принципы интерфейса

1. Одна страница — одна задача. Режимы переключаются на месте, а не секциями
   друг под другом.
2. Список → панель. Банк, препарат или тема открываются рядом, без ухода.
3. Плотность важнее декора: крупные числа, короткие подписи, таблицы.
4. Никаких «хабов-простыней»: если блок не нужен для текущего шага — его нет.
5. Все состояния (загрузка, пусто, ошибка, успех) видимы и говорят по-русски.

## Цвет

Семантические CSS-переменные, тема переключается атрибутом
`html[data-theme="…"]`:

| Токен | classic-light | Назначение |
|---|---|---|
| `--primary` | `#2563eb` | основное действие, ссылки |
| `--primary-dark` | `#1d4ed8` | hover/active |
| `--primary-soft` | `#eff6ff` | подложка активного пункта |
| `--accent` | `#3b82f6` | второй стоп градиента |
| `--background` | `#f9fafb` | фон страницы |
| `--card` | `#ffffff` | поверхность карточки |
| `--text` | `#0f172a` | основной текст |
| `--muted` | `#64748b` | вторичный текст |
| `--border` | `rgba(15,23,42,.16)` | декоративная граница |
| `--input-border` | `rgba(15,23,42,.55)` | граница поля (≥3:1) |

Статусы — всегда пара «текст + фон + рамка»: `--status-ok-*` (изумрудный),
`--status-warn-*` (янтарный), `--status-critical-*` (розово-красный),
`--status-info-*` (синий), `--status-neutral-*` (серый),
`--status-pending-*` (фиолетовый).

Темы: `classic-light`, `classic-dark`, `midnight`, `aurora-glass`,
`medical-glass`, `crystal-glass`, `aero-glass`. Стеклянные темы меняют только
поверхности и тени; семантика статусов не меняется.

Правило: цвет — не единственный носитель смысла. У статуса всегда есть подпись
или иконка. Контраст текста проверяется `npm run test:contrast`.

## Типографика

- Шрифт: Inter (`next/font`, кириллица), fallback `system-ui`.
- База: 15 px / 1.6.
- Заголовок страницы: `.page-title` — 24 px (sm: 30 px), 700, tracking-tight.
- Подзаголовок: `.page-subtitle` — 14 px, `--muted`.
- Микро-подпись: 11 px, 700, uppercase, tracking-wide — только для рубрик.
- Числа-метрики: 24–32 px, 800, `tabular-nums` для таймеров и счёта.

## Форма и пространство

- Радиусы: карточка 16 px (`rounded-2xl`), контрол 12 px (`rounded-xl`),
  пилюля 9999 px.
- Карточка: `.card` — фон `--card`, рамка `--border`, тень `--glass-shadow`,
  padding 20 px.
- Сетка: максимум 6xl (1152 px) для рабочих экранов, 3xl (768 px) для чтения и
  прохождения теста.
- Шаг отступов: 4 / 8 / 12 / 16 / 20 / 24 px.
- Липкие панели: шапка запуска и шапка прохождения (`top-2`, `backdrop-blur`).

## Компоненты

- Кнопки: `.btn-primary` (градиент primary→accent), `.btn-secondary` (рамка),
  `.btn-pill`, `.btn-danger`. Минимальная высота 40 px, на телефоне 44 px.
- Поля: `min-h-11`, радиус 12 px, граница `--input-border` при фокусе —
  `--primary`.
- Бейджи: `.badge-primary|success|warning|danger|neutral|pending`.
- Список банков: строка 56–72 px, слева название и метаданные, справа одно
  основное действие и вторичное «Вопросы».
- Карточка вопроса: один вопрос на экран, номер, текст, варианты, вердикт.
- Панель препарата: фото сверху, ниже «найти», «признаки», «отличия»,
  «ошибки», шаги.

## Состояния

Загрузка — скелетон той же формы, что и контент. Пусто — одна фраза и одно
действие. Ошибка — что случилось и кнопка «Повторить». Успех — зелёный статус,
но не только цветом.

## Чего избегать

- Длинных простыней из секций с якорями.
- Двух одинаковых экранов под разными вкладками.
- Второго выбора режима на том же пути.
- Декоративных градиентных обложек на рабочих экранах: акцент — только на
  действии и статусе.

## Как использовать со Stitch

1. `stitch::extract-design-md` держит этот файл в актуальном виде.
2. `stitch::generate-design` — макеты трёх поверхностей: каталог банков, экран
   запуска теста, практика по препаратам.
3. `stitch::react-components` — только как референс разметки; реализация идёт
   на существующих Tailwind-классах и токенах, без shadcn и смены стека.
