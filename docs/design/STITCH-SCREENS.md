# Stitch: экраны MEDBIOHIM

Проект: `projects/15048681218079585200` («MEDBIOHIM»).
Дизайн-система: `assets/df16484ef4f34530b66e6b16a0fc90db` (из `.stitch/DESIGN.md`).

Скачивать экран без MCP-клиента:

```bash
node scripts/stitch/mcp.mjs call list_screens '{"projectId":"15048681218079585200"}'
node scripts/stitch/mcp.mjs call download_file '{"name":"projects/15048681218079585200/files/<file>"}'
```

`download_file` отдаёт JSON: `image` — base64 PNG, `html` — исходник экрана.
Прямой `:download`-URL без MCP отдаёт 403, поэтому только через инструмент.

## Сгенерировано

| Экран | Назначение | ID | Артефакты |
|---|---|---|---|
| Тесты и банки вопросов | главный экран тестирования: назначения сверху, рекомендации, фильтры, дерево модулей | `projects/15048681218079585200/screens/cbcff4191b1347e6a7ed4ea7353074f3` | `docs/design/stitch-tests-catalog.png`, `docs/design/stitch-tests-catalog.html` |

Что на экране: шапка с вкладками «Назначенные / Каталог / История»; янтарная
карточка «Назначено преподавателем» со статусом «Не начато», метаданными
(вопросы, время, попытки, срок) и кнопками «Подготовка» / «Пройти назначение»;
«Практика: для вас» с процентными кружками; фильтры предметов и уровней
(«Все / База / Понимание / Применение»); список модулей со строками тем,
прогрессом, ссылкой «Вопросы» и кнопкой «Режим».

## Очередь (по программе §3)

1. Запуск банка: режим (подготовка / решение / контрольный / экзамен), объём
   «N из M», пирамида, липкая кнопка старта.
2. Прохождение: карточка вопроса одного ответа, нескольких, открытого,
   соответствия, последовательности, с формулой и изображением.
3. Результаты и разбор, «все вопросы и ответы».
4. История попыток и продолжение.
5. Редактор банков (преподаватель/админ).
6. Мобильные версии ключевых экранов.
